## Лабораторная работа №3. Работа с Markdown-разметкой и базовое использование LaTeX в документации проекта
#### Markdown — это простой и легкий язык разметки текста, созданный в 2004 году Джоном Грубером и Аароном Шварцем. Он позволяет форматировать текст с помощью обычных символов (например, звездочек или решеток), который затем легко преобразуется в чистый HTML
#### где он применяется:
#### Техническая документация: создание файлов README.md для проектов, базы знаний (например, в Notion, Obsidian).
#### Платформы для разработчиков: описание репозиториев, комментарии и оформление задач (Issues) на GitHub, GitLab и Bitbucket.
#### Зачем он нужен разработчикам
#### Скорость и фокус: позволяет оформлять текст (заголовки, списки, жирный шрифт, блоки кода), не отрывая руки от клавиатуры и не отвлекаясь на сложные визуальные редакторы (WYSIWYG).
#### Контроль версий: файлы .md являются обычным плоским текстом, поэтому любые изменения в документации легко отслеживать через систему Git (видеть diff).
